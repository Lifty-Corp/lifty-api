# API-owned shared contracts

- [HubSpot credential policy](hubspot-grant-policy.md): one pure policy for Node and Deno.

This repository owns the canonical source and distribution tooling. Consumers
vendor generated copies so they can build and deploy independently.

Business resource contracts (commercial profile, voice, Targeting, research
criteria and setup) are owned by the Lifty API request schemas and the GTM
database constraints and RPCs. They have no shared source in this directory.
